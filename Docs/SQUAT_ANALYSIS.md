# 深蹲阶段、次数与桌面采集界面：本步成品验收

在现有双摄动捕和脚部接地功能上增加深蹲阶段、完整次数及控制面板。现在可直接在“Motion Studio · 桌面实时监看”中操作采集和深蹲分析。先验收这一项，再推进导出与比赛材料。

## 打开并运行

1. 关闭旧的 Motion Studio **主控制台**。仅隐藏或关闭浮动监看窗口不会停止旧采集，旧程序仍会占用摄像头和回传连接。
2. 用 Unity 2022.3.62f3c1 打开本次任务工作树的 unity 项目，打开 Assets/动捕.unity。当前原始项目和已运行的旧 GUI 不会自动更新。
3. 双击配对 Python 工作树中的 run_squat_analysis.bat。启动后会直接打开桌面监看窗口，无需先启动采集。
4. 在该窗口点“摄像头设置”，使用原有主控制台选择前摄和侧摄。保持最近标定时的相机位置与编号，再点桌面窗口中的“启动采集”。当前本机标定会由既有管线加载；需要重测时可点“四点标定”。
5. Unity 点击 Play。桌面“深蹲分析”显示“已连接”后，双脚接地站直，等待建立站立基准，再点“开始 / 继续”。
6. 连续做 5 次完整深蹲，每次回到站直位置稍停。次数应依次变为 1、2、3、4、5。

动捕场景已安装全部组件。其他场景可选中带 HumanoidPoseDriver 的人物，执行菜单 Mocap > Install Squat Analysis Panel，并保存场景。

## 桌面窗口的操作

- 顶部：启动采集、停止采集、开始/停止录制、四点标定、摄像头设置。这些按钮调用现有主控制台和管线，不额外打开摄像头。
- 深蹲分析：显示完整次数、当前阶段、左右膝屈曲角（估计）和追踪提示；支持开始/继续、暂停深蹲、次数清零。
- “暂停深蹲”保留此前完整次数，摄像头仍在采集。“次数清零”清空次数并暂停，需要重新开始。
- 按钮操作会等待 Unity 回传确认。未进入 Play、组件缺失或回传中断时，深蹲按钮不可用；中断时保留最后收到的次数，阶段和膝角不再显示为实时数据。
- 原有前摄/侧摄画面仍在同一窗口；“Unity 动作诊断”默认折叠，点击可展开。
- 隐藏或关闭浮动窗口会继续采集。停止摄像头请点“停止采集”；退出整个程序请关闭主控制台。

Unity 右上角面板也可操作同一个计数器，两处显示以 Unity 为准。

## 本次计数规则

- 膝屈曲角 = 180° - 现有驱动的膝内角；站直约 0°。
- 初始站直：双膝屈曲角均 ≤15°，持续 0.25 秒。
- 动作开始：双膝均 ≥25°，持续 0.10 秒。
- 达到最低深度：双膝均 ≥45°，持续 0.10 秒。随后双膝均站直并持续 0.25 秒才计一次。
- 底部显示阈值为 65°，回升使用 4°方向滞回。阶段标签用于演示，不是精细生物力学分期。
- 两腿关键点必须齐全且各自可见度 ≥0.65；站立基准、下蹲和脚部接地必须已开启。
- 帧龄超过 250 毫秒、姿态帧停止推进、缺失关键点、时间倒退或捕获时间间隔超过 0.5 秒时，未完成动作会作废，恢复后先站直重新确认。
- 使用捕获时间；重复渲染帧不累计确认时长。只抬一条腿不会满足双膝深度条件。

阈值可在人物的 SquatAnalysisController 中调整；调整后重新进入 Play。先保持默认值完成一次验收，漏计时先看面板提示与双腿是否入镜。

## 最小现场验收

| 操作 | 预期 |
| --- | --- |
| 桌面窗口启动采集、Unity Play、站直并开始 | 同一窗口出现双摄画面、阶段、次数及膝角 |
| 连续完整深蹲 5 次 | 完整次数为 5；站立/下降/底部/上升可见 |
| 站直等待或在底部停留 | 次数不会持续增加 |
| 轻微屈膝，未达到双膝最低深度 | 不增加次数 |
| 深蹲途中暂停或遮挡腿部，然后站直恢复 | 不补计被中断的那一次；此前完整次数保留 |
| 在桌面窗口清零后重新开始 | Unity 确认后显示 0，站直确认后可再次计数 |
| 退出 Unity Play | 桌面深蹲按钮禁用，阶段与膝角停止实时显示 |

首次验收建议同时录制姿态。回放同一段 5 次动作有助于复查；录制文件留在本地 recordings/，不进 Git。

## 指标与验证边界

角度来自现有动捕驱动的计划腿方向，是几何估计，不是独立实测关节角。当前模型骨盆位移受骨架与 IK 限制，不能直接当成人体真实厘米位移；本步不输出力、关节力矩或功率。

自动测试验证计数规则、中断处理与桌面指令确认。另用本机 UDP 和模拟姿态验证开始、暂停、重复指令、清零；界面在 980×680 与 640×480 离屏检查。摄像头、遮挡、站位与角度估计的实际效果，仍须完成上表现场验收后确认。

## 代码入口

- Assets/SquatAnalysis/Core/SquatCycleCounter.cs：不依赖 Unity 的阶段与计数状态机。
- Assets/SquatAnalysis/Runtime/SquatAnalysisController.cs：读取现有姿态帧，进行有效性检查。
- Assets/SquatAnalysis/Runtime/SquatAnalysisOverlay.cs：Unity 右上角面板。
- Assets/SquatAnalysis/Runtime/SquatDesktopBridge.cs：接收本机桌面开始/暂停/清零指令。
- Assets/FootIkUdpSender.cs：沿用现有诊断回传，并附带深蹲状态与指令确认。
- Assets/Editor/SquatAnalysisSetup.cs：场景安装菜单与批处理入口。
- Assets/SquatAnalysis/Tests/EditMode/：计数与指令去重测试。

新组件只读取现有驱动，不写人物骨骼，也不创建 MediaPipe 处理器。
